# Security policy

## Supported versions

We fix security issues in the latest minor release only. Upgrade to it to get
fixes.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub: open the repository's **Security** tab and
click **Report a vulnerability**. Include the natpair version, what an attacker
can do, and the steps to reproduce it.

We aim to acknowledge your report within 3 business days. We will work with you
on a fix and agree on a disclosure date before anything is made public.
